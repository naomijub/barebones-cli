# Greeter Plugin

## Upper case greeting

```console
$ barebones-cli greeter -- --uppercase julia
[INFO]: greeter -   Loaded: greeter v0.1.0
greeter: HELLO, JULIA!

```

## Simple greeting

```console
$ barebones-cli greeter julia
[INFO]: greeter -   Loaded: greeter v0.1.0
greeter: Hello, julia!

```

## Empty greeting

```console
$ barebones-cli greeter
[INFO]: greeter -   Loaded: greeter v0.1.0
greeter: Hello, World!

```
